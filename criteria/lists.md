# List criteria (sample)

Copy this file to `.draftsman/criteria/lists.md` in your project and edit it to make it yours.

A bullet list is right when its items are parallel, independent and short: steps, options, ingredients, a checklist. Leave those alone.

Propose a change when a list is really something else:

- **A table.** The items share the same parts: each names a thing and gives two or more facts about it in the same order ("Nile: 36 months, $950M"). Make it a table with one column per fact.
- **An argument.** Each item depends on the one before ("because", "so", "which means"), or the last item is the conclusion. Make it a paragraph, so the reasoning reads as reasoning.
- **A paragraph.** There are only two items, or the items are full sentences that read better joined, or the list exists only to break up text.
- **A numbered list.** The order matters (steps, a ranking), but it's written as bullets. Number it.

Don't propose a change when:

- The list is a summary block or a list of links.
- The change would only reword items; that's editing, not structure.

For each proposal, show the list as it is and as it would be, and say in one line why.
